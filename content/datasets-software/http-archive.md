## Instrumentation

We instrumented the [HTTP Archive](https://httparchive.org/) crawl with custom
metrics to detect and measure the adoption of different Privacy Sandbox APIs.

Links to Custom Metrics Tracking Issues:
- https://github.com/HTTPArchive/custom-metrics/pull/129
- https://github.com/HTTPArchive/custom-metrics/pull/131

## HTTP Archive Host Categories

We collaborated with the [HTTP Archive](https://httparchive.org/) to classify
with the Topics API a large dataset of about 147M hostnames that correspond to
31M sites:

- Documentation: [https://har.fyi/reference/functions/get_host_categories](https://har.fyi/reference/functions/get_host_categories)
- Repository: [https://github.com/yohhaan/httparchive-topics-classification](https://github.com/yohhaan/httparchive-topics-classification)
