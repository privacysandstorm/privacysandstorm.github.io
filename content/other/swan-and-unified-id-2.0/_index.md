SWAN and Unified ID 2.0 are two proposals from different actors but with some similarities; they both propose to assign users a pseudonymous identifier that can be used for cross-site tracking and would not be stored in third-party cookies. SWAN would do so through bounce tracking, while Unified ID 2.0 would use identifiers such as email addresses.

### SWAN
- **Proposed by:** 51Degrees
- [Explainer](https://github.com/SWAN-community/swan)

### Unified 2.0
- **Proposed by:** IAB Tech Lab
- [Explainer](https://github.com/IABTechLab/uid2docs)
- [Website](https://unifiedid.com/docs/intro)
