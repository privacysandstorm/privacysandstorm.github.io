**Title:** [Cookies Chapter - Attestation Measurement](https://almanac.httparchive.org/en/2024/cookies#attestation-file)

**Authors:** Yohan Beugin, Sam Dutton, Yana Dimova, Rowan Merewood, Barry Pollard

**Abstract/Summary:** Chrome ships with a preloaded file containing a list of domains that have an attestation file registered. Currently, this list contains 257 distinct domains (version 2024.10.7.0) that have enrolled to call the following APIs: Attribution Reporting, Protected App Signals (Android only), Private Aggregation (Chrome only), Protected Audience, Shared Storage (Chrome only), and Topics.
